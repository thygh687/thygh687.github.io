模块一第 2 章：CPU 是怎么执行指令的

组成原理2026-11-24 · 模块一

CPU 的工作就是一个循环，不停重复四个步骤：取指、译码、执行、写回。你打开的每个程序、点的每次鼠标，最后都是这个循环在干活。

四个步骤

取指：程序计数器记着下一条指令在内存的哪个地址，CPU 按这个地址把指令拿来，放进指令寄存器。译码：控制单元看懂这条指令是要干什么。执行：让相应的部件去干活，比如让 ALU 做加法，或者让内存读写数据。写回：把结果存回寄存器。然后程序计数器指向下一条，循环继续。

关键部件

程序计数器（PC）：下一条指令的地址。寄存器：CPU 手头的小抽屉，放正在用的数据，速度最快、容量最小。ALU：算术逻辑单元，负责加减乘除和比较。控制单元：指挥，负责把指令翻译成各个部件的动作信号。时钟：卡节奏，每跳一下往前走一步。

指令就是二进制数

一条指令本身也是一串 0 和 1，前几位是操作码（干什么，比如加法），后面是操作数（对谁干，比如哪两个寄存器）。程序就是一长串这样的指令，存在内存里等 CPU 一条一条取。

主频和多核

主频比如 3GHz，就是时钟每秒跳 30 亿下。主频越高一般越快，但不是唯一决定速度的：一次能干多少活、缓存够不够大，同样重要。现在的 CPU 都是多核的，等于好几个 CPU 并排干活，一个核跑一个程序，互不耽误。

视频讲解：CPU Architecture Explained（YouTube，英文，可开自动字幕，约 8 分钟，讲 ALU、寄存器、控制单元和指令周期）

动手做

1. 打开任务管理器 → 性能 → CPU，看自己的 CPU 型号、主频、核心数和逻辑处理器数。
2. 打开一个程序（比如浏览器），看 CPU 占用率的变化；再同时打开几个程序，看占用率怎么分。

避坑

别只盯着主频买电脑，核心数、缓存、架构同样重要；CPU 占用率高先看是哪个进程在跑，别急着加硬件；取指译码执行这个循环是全书最重要的概念之一，一定要真懂。
