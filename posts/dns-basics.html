DNS 是怎么回事：ping 一下就明白了

2026-11-06

上网的时候，我们输入的是网址，比如 example.org；但电脑真正要找的，是一个 IP 地址。把网址翻译成 IP 地址的那一步，就是 DNS 干的活。

可以这样理解：DNS 就是互联网的电话本。你报一个名字，它帮你查到号码。

动手验证

打开 PowerShell，输入：

ping example.org

返回的结果里会有一个 IP 地址，那就是 example.org 这个名字对应的号码。名字没变，号码可能会变——这也是 DNS 的工作之一。

为什么安全工程师要懂这个

很多攻击就发生在“翻译”这一步：如果你查到的号码是假的，你就会连到假的网站。所以学安全，DNS 是绕不开的第一课。
