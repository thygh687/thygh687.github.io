第 5 课：网站是怎么打开的

网络2026-11-24 · 阶段一

在浏览器里输入一个网址、按回车，背后发生了四步：

1. DNS 查地址

先把网址翻译成 IP 地址（第 4 课讲过）。

2. 浏览器发请求

浏览器向那个 IP 发一个 HTTP 请求，大意是：“把这个页面给我。”

3. 服务器回响应

服务器收到请求，把页面的内容发回来，同时带一个状态码：200 是成功，404 是找不到，500 是服务器自己出错了。

4. 浏览器画页面

浏览器拿到 HTML、图片、样式，一点一点画成你看到的页面。

HTTPS 是什么

HTTPS 就是 HTTP 加了一层加密。地址栏有小锁标志，传输的内容别人偷看不到、也改不了。现在的网站基本都是 HTTPS。

动手做

打开 example.org，按 F12 → 点“网络”，再刷新页面。看一堆请求冒出来，点其中一个，看它的状态码是不是 200。
