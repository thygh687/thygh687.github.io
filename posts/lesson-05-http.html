第 5 课：网站是怎么打开的

网络2026-11-24 · 阶段一

在浏览器里输入一个网址、按回车，背后发生了四步：

1. DNS 查地址

先把网址翻译成 IP 地址（第 4 课讲过）。这一步出问题，浏览器报的往往是“找不到网站”“无法解析主机名”——意思是名字都没翻译出来，后面的路根本没开始走。

2. 浏览器发请求

浏览器向那个 IP 发一个 HTTP 请求，大意是：“把这个页面给我。”请求里不只一句话，还带着几样东西：你要的是哪个页面（路径）、你用的什么浏览器、你之前在这网站留下的凭证（Cookie）。发请求之前，浏览器要先和服务器把“路”接通：先建立连接（TCP），如果是 HTTPS，还要再做一次加密握手——双方对一下暗号，商量好接下来用什么钥匙加密，然后才开始传真正的请求。也就是说，HTTPS 的页面在发请求之前，就多了一道“先加密、再说话”的手续。

3. 服务器回响应

服务器收到请求，把页面的内容发回来，同时带一个状态码：200 是成功，404 是找不到，500 是服务器自己出错了。状态码的第一位数字就说明了是哪一类事：

  • 2xx（成功）：200 是最常见的“好的，给你”。
  • 3xx（换地方了）：301、302 是“这个页面搬家了，去新地址找”——浏览器会自动跟过去，所以你常常感觉不到它发生过。
  • 4xx（你的问题）：404 是“这个页面不存在”，可能是地址打错了，也可能是页面被删了；403 是“这个页面存在，但不让你看”，多半是权限问题——登录了才让看，或者你的 IP 被拦了。
  • 5xx（服务器的问题）：500 是服务器自己出错了，502、503 是服务器后面的服务没接上、或者忙不过来了。这种时候刷新也没用，等一会儿再试。

状态码通与不通各意味着什么？200 但页面是空白的：路和服务器都没问题，问题在页面本身——比如它要加载的脚本、样式没回来，浏览器画不出来。404：先看地址有没有打错一个字母，再看是不是收藏夹里的旧链接失效了。403：别反复刷，先确认自己登录了没有、账号有没有权限。500、502、503：不是你的错，是对方服务器的事，换个时间再试；但如果每个网站都 5xx，先查自己的网（回第 3 课的三段定位）。

4. 浏览器画页面

浏览器拿到 HTML、图片、样式，一点一点画成你看到的页面。注意：一个页面不是一次请求就拿完的。HTML 只是架子，里面的图片、样式、脚本，浏览器要再发几十个请求一个一个去拿——所以你在 F12 的“网络”里看到一堆请求，是正常的。一个页面打不开，不一定是主页面出了问题，可能是它引用的某个脚本没加载回来，页面就卡在半截上。

HTTPS 是什么

HTTPS 就是 HTTP 加了一层加密。地址栏有小锁标志，传输的内容别人偷看不到、也改不了。现在的网站基本都是 HTTPS。但加密到底加密了什么、不加密什么，要分清楚：

两个最常见的误区：第一，“有小锁就是安全的网站”——不对。小锁只说明这条路加密了，不说明对方是谁；钓鱼网站也可以有小锁，证书是谁都能申请的。判断网站真不真，看域名本身对不对（第 4 课），不是看有没有锁。第二，“HTTPS 了就什么都藏住了”——不对。你访问了哪个域名、连了哪个 IP，网络上还是能看到；加密的是你和网站之间说的内容，比如你输入的密码、填的表单。加密的原理（第 14 课）和钓鱼的识别（第 12 课）后面会细讲。

老师经验：网站打不开，F12 的“网络”标签页就是第一现场，别急着重启浏览器。先看主请求的颜色：红色、状态码 404，先核对地址有没有打错；403，先确认登录和权限；500、502、503，不是你的错，等一会儿再试。还有一种最容易误判的情况：状态码全是 200，页面却是空白的——这时候往下翻，看是哪个脚本或样式请求失败了，页面是被它拖垮的。最后一条是安全红线：浏览器弹出“证书有问题”“连接不是私密连接”，千万别点“继续前往”——证书警告的意思是“对方身份对不上”，这时候输密码，等于把密码递给了一个身份不明的人；真有急事，先换个网络、换个时间再试，或者直接联系网站方核实。

避坑：不要在没有小锁的 HTTP 网站上输入密码、输手机号——明文传送，同一个 Wi-Fi 下的人都能看到。不要点邮件、聊天记录里“账号异常、点此验证”的链接去登录——真网站自己输网址进，不要走别人给的链接。抓包、改请求之类的实验，只在自己的虚拟机里对自己搭的网站做，绝不在真实网站上练手。

动手做

打开 example.org，按 F12 → 点“网络”，再刷新页面。看一堆请求冒出来，点其中一个，看它的状态码是不是 200。再点一个图片请求，看它的状态码和大小——一个页面背后原来是几十个请求拼起来的。最后看一眼地址栏的小锁，点开它，看浏览器说这个连接是怎么加密的。

四步走完，一个网站就打开了。下一课把前五课串起来，用三个命令亲手验证一遍：第 6 课：动手：ping、ipconfig、nslookup。前面打下的底子——第 3 课的地址和端口、第 4 课的 DNS——都是那一课要对上号的东西。

本课小结
  • 打开网站是四步：DNS 查地址、浏览器发请求、服务器回响应、浏览器画页面；一个页面背后常常是几十个请求。
  • 状态码看第一位：2 成功、3 搬家、4 你的问题（404 找不到、403 不让看）、5 服务器的问题。
  • HTTPS 是 HTTP 加加密：内容别人看不懂、改了会被发现；但域名和 IP 仍然可见。
  • 小锁不等于网站可信：钓鱼网站也可以有小锁，真假看域名本身。
  • 证书警告别点“继续”：那是对方身份对不上，输密码等于递给陌生人。
