第 19 课：电脑的全部零件：主板、芯片组、电源、显卡、接口

预备课2026-11-25 · 预备课第 19 课

第 1 课讲过一台电脑有四个角色：CPU 负责算，内存负责临时放正在用的东西，硬盘负责长期存东西，操作系统负责指挥。这四个角色是对的，但一台真电脑远不止这四样：CPU 要插在什么地方？内存条怎么固定？显卡和硬盘靠什么连到 CPU 上？电从哪里来？显示器、键盘、网线又插在哪里？这一课就把机箱盖子打开，把全部零件一个一个认全——不是为了让你去组装电脑，而是因为以后排错、看配置、判断一台电脑“卡在哪里”，全靠认得这些零件。

主板：所有零件的底座

主板（Motherboard）就是一块最大的电路板，机箱里所有零件都要直接或间接连到它上面。CPU 插在主板正中的插槽里，内存条插在 CPU 旁边的内存插槽里，显卡插在最长的扩展插槽里，硬盘连在主板边缘的接口上，电源的线也插在主板上。主板本身不算数、不存数据，它的工作是“接线”：把电和信号送到每个零件，让它们能互相说话。

主板有大小之分，常见的板型有三种：ATX 是标准大板，插槽多、接口全，台式机最常见；Micro-ATX 是小一点的板，插槽少两个，适合小机箱；Mini-ITX 是最小的板，只有一条显卡插槽、两条内存插槽，适合迷你主机。板型只决定“能装多少东西”，不决定快慢——同一块 CPU，插在大板和小板上跑起来是一样快的。买电脑时看一眼板型，主要是确认：机箱装得下吗？以后想加一块显卡、加一条内存，还有空位吗？

芯片组：主板上的交通管理员

主板上除了插槽，还有一组很重要的芯片，叫芯片组（Chipset）。可以把它想成主板上的交通管理员：CPU 和内存、显卡、硬盘、USB 接口之间的数据，都要经过它来调度。芯片组的型号决定了主板支持什么：支持第几代 CPU、支持 DDR4 还是 DDR5 内存、有几个 USB 接口、能不能超频。同一代 CPU，不同芯片组的主板，功能和价格能差好几倍。

一个常见的误会要先说破：芯片组不是 CPU 的一部分，也不是显卡。它是主板的一部分，买主板就是在买芯片组。所以“这台电脑是什么配置”不能只看 CPU，还要看主板芯片组——它决定了这台电脑的“上限”：内存最高能上多少、硬盘接口有几个、以后能不能升级。

CPU 插槽与内存插槽：插错了就装不上

CPU 插槽（Socket）是主板上放 CPU 的地方。不同牌子、不同代的 CPU，插槽不一样：英特尔的 LGA 1700 和 AMD 的 AM5，针脚数量和形状都不同，互相装不上。换 CPU 之前，先查主板支持什么插槽，再查芯片组支持第几代 CPU——插槽对了、芯片组不支持，一样点不亮。

内存插槽旁边通常写着 DDR4 或 DDR5。DDR 是内存的技术代数，数字越大越新：DDR4 是上一代，DDR5 是现在的主流。关键是：DDR4 的内存条插不进 DDR5 的插槽，缺口位置都不一样——这是故意设计的防呆口，插错了根本插不进去，硬插会把条子或插槽弄坏。内存条一般成对插：两条一样的内存插在主板说明书指定的两个槽位上，组成“双通道”，速度比单条快不少。装机时最常见的低级错误，就是把两条内存插成了单通道，白白丢了性能。

电源：功率不是越大越好，但小了会出事

电源（PSU）把家里 220V 的交流电变成电脑里各零件要用的直流电。电源上标的瓦数（比如 550W、750W）是它最多能输出多少功率，不是它一直耗多少电——电脑只用 200W 时，750W 的电源也只输出 200W 左右。选电源的原则是：够用再留一点余量。CPU 加显卡的功耗，再加 100W 左右给其他零件，就是大概需要的功率。电源功率不够，最常见的症状不是“开不了机”，而是“一玩游戏就黑屏重启”：平时办公功耗低没事，显卡一满载就超过电源能力，整机断电保护。

电源给主板供电靠两组线：24 针主供电插在主板边缘，给主板和插在主板上的零件供电；8 针（或 4+4 针）CPU 供电插在 CPU 插槽附近，专门给 CPU 供电。独立显卡还要单独供电：中高端显卡要从电源上再接一两根 6+2 针 PCIe 供电线。维修时遇到“新装的显卡点不亮”，先查供电线插全了没有——这是比驱动问题更常见的真原因。

显卡：算图的那块卡

显卡（GPU）是专门负责算图形的零件。CPU 也能算图，但它是“什么都算一点”的通才；显卡是“一次算成千上万个像素”的专才，画游戏画面、剪视频、跑 AI 模型，都是它的活。显卡分两种：集成显卡（核显）做在 CPU 里面，够办公、看视频、上网用；独立显卡是一块单独的卡，插在主板最长的 PCIe ×16 插槽上，性能强得多，也贵得多、耗电多得多。

显示器接在哪块显卡上，画面就是哪块显卡算的——这是新手最常犯的错：装了独立显卡，显示器却还插在主板后面的接口上，画面走的是核显，独立显卡全程闲着，游戏照样卡。正确做法：显示器插在独立显卡自己的 HDMI 或 DP 接口上。

存储接口：SATA、NVMe、M.2 别再混了

硬盘连主板有两种主流方式。SATA 是老接口：用一根数据线连主板、一根电源线连电源，2.5 英寸固态硬盘和机械硬盘都用它，速度上限约 550MB/s。NVMe 是新协议：走 PCIe 通道，速度是 SATA 的好几倍，现在主流的 M.2 固态硬盘用的就是它，速度常见的有 3500MB/s、7000MB/s。

M.2 不是协议，是插槽的形状：一个长条形的小插槽，插上去用一颗螺丝固定。M.2 插槽里插的可以是 NVMe 盘，也可以是 SATA 协议的 M.2 盘——长得一样，速度差几倍。买硬盘时要看清三件事：接口形状（M.2 还是 2.5 英寸 SATA）、协议（NVMe 还是 SATA）、主板上有没有对应的空位。模块一第 3 章会把存储金字塔讲透，第 23 章会讲 PCIe 和总线是怎么给这些设备分路的。

扩展插槽与接口：电脑和外界说话的口子

除了显卡，PCIe 插槽还能插声卡、网卡、采集卡、额外的 NVMe 扩展卡。PCIe 插槽按长度分 ×1、×4、×16，数字越大、通道越多、速度越快。显卡插 ×16 的长槽，其他小卡插 ×1 的短槽就行——短卡能插进长槽，长卡插不进短槽。

机箱后面的接口是电脑和外界说话的口子：USB 接鼠标键盘、U盘、移动硬盘（USB 3.x 是蓝色的口，速度比黑色 USB 2.0 快得多）；HDMI 和 DP（DisplayPort）接显示器，DP 一般支持更高的刷新率；网口（RJ45）接网线；音频口接耳机音箱。分清这些口，排错时才知道“网线插对没有”“显示器接在哪个口上”这些基本问题该怎么查。

散热：热是电脑的头号敌人

CPU 和显卡工作时会发很多热，热散不掉，电脑就会降频变慢，严重了直接死机、关机。散热靠三样东西：散热器（CPU 上面那个带风扇的大铁块，把热从芯片导出来）、机箱风扇（把机箱里的热空气抽出去）、硅脂（涂在 CPU 和散热器之间、填满微小空隙的一层膏，干了、涂少了，散热就变差）。灰尘是散热的天敌：风扇和散热片上积一层灰，风就吹不进去，温度能高十几度。电脑越用越卡、风扇越转越响，先别急着怀疑中毒，拆开侧板看看灰、看看温度，很可能就是散热问题。

老师经验：修电脑这么多年，我总结出一条：客户说“电脑突然黑屏”，十次里有七八次不是系统坏了，而是硬件到了极限。最常见的一幕是：一台配了高端显卡的电脑，电源只有 450W，平时办公好好的，一打开游戏就黑屏重启——换个够功率的电源，问题就没了。还有一幕是：客户说“电脑越用越卡”，打开一看，CPU 散热器上糊了厚厚一层灰，温度常年 95 度，CPU 一直在降频保命，清完灰、换了硅脂，速度立刻回来。修电脑先看硬件清单和温度，再看系统和软件——顺序反了，会走很多弯路。

动手做

只在自己的 Windows 电脑上做，不拆机、不动硬件。1. 按 Ctrl+Shift+Esc 打开任务管理器，点“性能”选项卡，记下 CPU 型号、内存大小和类型（DDR4/DDR5）、硬盘类型、显卡型号。2. 按 Win+R，输入 msinfo32 回车，记下主板型号、BIOS 版本、处理器和已安装内存。3. 右键“开始”菜单打开设备管理器，展开“显示适配器”“磁盘驱动器”“网络适配器”，记下每类下面有几个设备、分别叫什么。4. 把三处看到的信息整理成一份一页纸的硬件清单，存进第 18 课建的学习仓库里：CPU、内存（容量+代数）、硬盘（容量+接口）、显卡（核显还是独显）、主板型号、电源功率（如果知道的话）。以后每学一课排错，都先翻这份清单。

避坑

别把 DDR4 内存往 DDR5 插槽里硬插——缺口对不上就是装不上，硬插会损坏条子或插槽；别以为电源瓦数越大越好——够用加余量就行，关键是品牌和质量，杂牌大功率电源比品牌小功率电源更危险；别把显示器插在主板接口上却指望独立显卡工作——显示器接在哪块卡上，哪块卡才干活；别拿 M.2 的形状当速度——M.2 只是插槽形状，NVMe 和 SATA 的 M.2 盘速度差几倍，买之前看清协议；别在机箱里乱拔线练手——这一课只看不动手拆，拆机换件等模块一学完硬件原理再说。

这一课认全了零件，下一课换个角度：同样的硬件，装上不同的操作系统，电脑就变成完全不同的工具——第 20 课：操作系统有哪些。而这些零件在底层到底怎么配合工作——CPU 怎么执行指令、内存怎么分层、总线怎么传数据——是模块一第 3 章、第 22 章和第 23 章要讲透的事。

本课小结
  • 主板是所有零件的底座，板型（ATX/Micro-ATX/Mini-ITX）只决定能装多少东西，不决定快慢；芯片组是主板上的交通管理员，决定主板支持什么 CPU、内存和接口。
  • CPU 插槽和内存代数要对得上：DDR4 条子插不进 DDR5 插槽；两条一样的内存插对槽位组成双通道才快。
  • 电源功率要够用再留余量，24 针供主板、8 针供 CPU、独立显卡还要单独接 PCIe 供电线；功率不够最常见的症状是一玩游戏就黑屏重启。
  • 存储接口分清三件事：形状（M.2/2.5 英寸 SATA）、协议（NVMe/SATA）、主板上有没有空位；M.2 只是形状，不是速度。
  • 显示器接在哪块显卡上，哪块显卡才干活；散热不良会让 CPU 降频变慢，灰尘和干掉的硅脂是常见原因。
