第 9 课：文件权限与用户管理

Linux2026-11-24 · 阶段二

第 1 课说过，操作系统是大管家，定规矩：哪个程序能读哪个文件、谁能装软件、谁能改系统设置，都是它说了算。这一课讲的就是这套规矩在 Linux 里的样子。学安全有一半是在学权限——权限设错了，病毒就长驱直入。

权限是什么

Linux 里每个文件都有权限，规定了谁能读、谁能写、谁能执行。执行 ls -l，最前面那一串就是权限，比如 -rw-r--r--。这串字符不是乱码，是三组规矩拼在一起，每组三个字母。

rwx 三个字母

r 是读，w 是写，x 是执行。权限分三组：文件所有者、所有者所在的组、其他人。比如 rwx r-x r-- 就是所有者能读能写能执行，同组的人能读能执行，其他人只能读。

同一个字母，放在文件上和放在目录上，意思不一样——这是新手最容易晕的地方：

  • 对文件：r 能打开看内容；w 能改、能保存；x 能当成程序运行。没有 x 的脚本，你写得再对，系统也不让它跑，只会报 Permission denied。
  • 对目录：r 能列出里面有什么（ls）；w 能在里面新建、删除、改名；x 能“走进去”（cd）和访问里面的文件。目录没有 x，哪怕有 r，也只能看到名字，打不开里面的东西——很多人卡在这里，以为是文件权限错了，其实是目录缺了 x。

所以排错时要看两层：文件本身的权限，和它所在目录的权限。只改一层，问题可能还在另一层。

chmod 改权限

chmod 755 文件 是最常见的改法：三个数字分别对应三组人，7 是读+写+执行，5 是读+执行，4 是只读。记不住数字也没关系，chmod +x 文件 就是给它加上执行权限。

数字是怎么来的？r=4、w=2、x=1，每组把有的加起来：rwx 是 4+2+1=7，r-x 是 4+1=5，r-- 是 4。所以 755 就是“所有者全有，同组和其他人读+执行”——程序和目录最常用的权限；644 是“所有者读写，其他人只读”——普通文件最常用的权限；600 是“只有所有者能读写”——放密码、密钥这类私密文件就该用它。

两种写法各有用途：数字写法（chmod 755）一次把三组定死，适合从头定规矩；符号写法（chmod +x、chmod o-w 文件）只改一项、不动别的，适合微调——比如只给所有人去掉写权限，又不想动读和执行。还有 chmod -R，递归改整个文件夹，但要小心：它会把里面的每一个文件都改掉，改错了恢复起来很麻烦，敲之前先确认路径。

老师经验：见过最多的权限事故不是“权限太严”，是“权限太松”——图省事直接 chmod 777，所有人能读能写能执行，问题是暂时没了，但门也彻底敞开了。安全事件里，很多入侵就是从一个 777 的目录、一个所有人可写的脚本开始的。排错的正确顺序是：先看清现在是什么权限（ls -l），再想清楚应该是什么权限，最后只改最小的那一项。改权限之前问自己一句：改完之后，最坏是谁能干什么？答不上来就先别改。还有，脚本跑不起来先别急着加权限，先看第一行和报错——缺 x 是一回事，文件本身写错了是另一回事。

避坑：一是别用 777 当万能钥匙，它是“所有人什么都能干”，不是“修好了”；二是改系统目录（比如 /etc）的权限之前，先想想有没有备份、能不能恢复——系统文件权限改错，整个系统都可能起不来；三是 chmod 改的是权限，不是所有者，想换主人要用 chown，这两个命令别混了。

root 和 sudo

root 是超级用户，什么都能干，也最危险。平时用普通用户，需要管理员权限的时候在命令前面加 sudo，临时借用一次。

为什么这样设计？因为 root 没有“你确定吗”——它删系统文件不问、改配置不问、装软件不问。普通用户加 sudo 的好处是每一次提权都是一次显式的决定：你知道自己正在干一件需要管理员权限的事，输密码的那一刻就是一次停顿和确认。长期用 root 登录，等于把保险拆了开车，出事只是时间问题。

相关命令一次认全：whoami 看你现在是谁；id 看你的用户、组和编号；sudo whoami 会回答 root——因为它就是用 root 的身份跑的；sudo -i 是临时变成 root 的 shell，用完马上 exit 出来，别在里面逗留。用户管理上，sudo adduser 新用户名 建用户，sudo passwd 用户名 设密码，sudo deluser 用户名 删用户，groups 用户名 看他属于哪些组。删用户之前先想好他的文件归谁——人删了，文件还在，只是没了主人。

什么时候该用 sudo，什么时候不该？装软件、改系统配置、看系统日志——该用。读自己的文件、写自己的笔记、跑自己的脚本——不该用。凡是 sudo 后面跟的命令，先问一句“这件事真的需要管理员吗？”不需要就别加。还有一条安全上的铁律：sudo 的密码就是你的登录密码，别把它告诉别人，也别为了省事把用户设成“不用密码就能 sudo”。

动手做

建一个文件，ls -l 看它的权限，再 chmod 600 文件，再 ls -l 看变化。最后 sudo whoami，看它回答什么。加做两步：建一个目录，故意把它改成没有 x（chmod 644 目录），试试 cd 进去会报什么错，再改回来；再用 id 看一眼自己的用户和组——下一课查端口的时候，ss -tlnp 看不到程序名，往往就是因为没加 sudo，权限不够。

本课小结
  • ls -l 最前面一串是三组规矩：所有者、同组人、其他人，每组 rwx 三个字母；第 1 位是类型（- 文件，d 目录）。
  • rwx 在文件和目录上意思不同：目录缺了 x 就进不去、打不开里面的文件；排错要看文件和目录两层。
  • chmod 数字写法一次定死三组（r=4、w=2、x=1），符号写法只改一项；755 给程序和目录，644 给普通文件，600 给私密文件。
  • 永远别用 777 当万能钥匙；root 什么都能干所以最危险，平时用普通用户，需要时 sudo 临时借用一次。
  • whoami、id、adduser、passwd 是用户管理的基本功；下一课用网络命令时，权限不够会直接反映在输出上。
