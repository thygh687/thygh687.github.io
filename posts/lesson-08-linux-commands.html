第 8 课：Linux 常用命令

Linux2026-11-24 · 阶段二

Linux 主要靠命令行。先记住这十个，天天用得上。打开第 7 课装好的虚拟机里的终端，一个一个敲。命令不用背，理解它在干什么，敲三遍手就记住了。

先认路：你在哪里，周围有什么

Linux 里没有 C 盘 D 盘，整个系统是一棵从根目录 / 长出来的树。你家目录是 /home/你的用户名，平时都在这里活动。

pwd 看你现在在哪个目录（print working directory）；ls 列出当前目录的东西；cd 目录名 换个目录；cd .. 回上一级；cd ~ 直接回家。路径有两种写法：绝对路径从根写起，比如 /home/用户名/练习，在哪敲都一样；相对路径从现在的位置算，比如 cd 练习，换个目录结果就不同。新手最常见的错就是把相对路径当成绝对路径——命令本身没错，只是“现在在哪”跟你想的不一样，先 pwd 看一眼再敲。

两个提效的习惯，现在就养成：一是 Tab 补全，输一半按 Tab，系统帮你把剩下的补出来，既快又不会打错字；二是 方向键上翻历史，按 ↑ 就能找回上一条命令，不用重新打。排错时还会用到 history，它列出你敲过的所有命令——别人问“你刚才到底干了什么”，它就是证据。

建、复制、移动、删除

mkdir 名字 建文件夹；cp 源文件 目标 复制；mv 旧名 新名 移动或者改名；rm 文件 删除。注意：rm 删了没有回收站，删之前先想清楚。

这几个命令各有一个新手必踩的坑：

  • cp 复制文件夹要加 -r。cp 文件夹 目标 会报错，因为默认只复制单个文件；cp -r 文件夹 目标 才把整个文件夹连里面的东西一起搬走。报错不是命令坏了，是你少了一个参数。
  • mv 既是移动也是改名。mv 旧名 新名 在同一个目录里就是改名，目标写成另一个目录就是移动。文件“不见了”的时候，先想想是不是被 mv 到别处去了。
  • rm 没有后悔药，尤其 rm -rf。-r 是递归删整个文件夹，-f 是不问直接删，合起来就是“删光、不确认”。在虚拟机里练可以，但永远别在不确定的目录里敲，更别对着 / 或家目录敲。删之前先 ls 确认自己在哪、要删的是什么——第 7 课的快照就是最后一道保险，但好习惯比保险更重要。
  • 删错了怎么办？第一时间停手，别再往同一块磁盘写东西（新写入会覆盖刚删的数据），然后从快照恢复。数据取证能恢复“已删除”文件（第 1 课讲过原理），但那是事后补救，不是日常操作。

看内容、找文字

cat 文件 把文件内容打印出来；grep 文字 文件 在文件里找指定的文字；man 命令 看这个命令的说明书，不会就查它。

这三个要讲深一点，因为它们是排错的基本功：

  • cat 只适合看小文件。文件一大，它会把几千行一口气刷过去，根本看不清。大文件用 less 文件，可以上下翻、按 / 搜索、按 q 退出——看日志的时候天天用它。
  • grep 是在文字里钓鱼。grep 错误 日志文件 只把含“错误”的行挑出来，几万行的日志一下子只剩几行。加上 -i 不区分大小写、-n 显示行号、-r 在整个文件夹里递归找。以后查日志、查配置，grep 是第一把筛子。
  • man 是说明书，不是字典。man ls 打开 ls 的完整手册，用 / 搜关键字、q 退出。看不懂别硬啃，先看开头的“描述”和例子部分。更轻量的办法是 命令 --help，只列常用选项，够应急用。

报错也要会读。三种报错最常见，各有各的意思：No such file or directory 是路径错了——先 pwd、再 ls，确认文件到底在不在这；Permission denied 是权限不够——不是命令错了，是你这个用户没资格碰它，第 9 课专门讲权限；Is a directory 是你把文件夹当文件用了，比如对文件夹用了 cat，或者 cp 文件夹忘了 -r。报错不是“电脑坏了”，它是系统在告诉你哪一步不对。

老师经验：排错时，先复述三件事再动手：我在哪（pwd）、我面前有什么（ls）、我刚才敲了什么（history）。一半以上的“灵异问题”都是这三件事里有一件跟想的不一样——在 A 目录敲了针对 B 目录的命令，或者文件名打错一个字母。还有一条：敲 rm 之前，先把命令里的路径读一遍，大声读出来也行；凡是 rm -rf 后面跟的路径让你犹豫超过三秒的，先停下来，用 ls 看一眼再说。真正出事的从来不是命令本身，是手比脑子快。

避坑：一是别在根目录 / 附近练 rm 和 mv，在家目录建个“练习”文件夹，所有实验都在里面做；二是文件名里别用空格，空格会被当成两个参数，我的 文件 会被认成两个东西——要用就用下划线；三是 cat 大文件之前先 ls -l 看一眼大小，几 MB 以上就换 less。

动手做

在虚拟机里把上面每个命令敲一遍：建一个文件夹，进去，建一个文件，写一句话进去，再用 cat 看、用 grep 找，最后删掉。加做两步：故意敲错一次路径，看 No such file or directory 长什么样；再用 man ls 查一下 ls -l 是什么意思——ls -l 的输出，下一课要逐字拆开讲。

本课小结
  • Linux 是一棵从 / 长出来的树：pwd 看位置，ls 看内容，cd 换地方；绝对路径从根写起，相对路径看你现在在哪。
  • mkdir、cp、mv、rm 管增删改：cp 文件夹要加 -r；mv 既是移动也是改名；rm 没有回收站，rm -rf 尤其要慢半拍。
  • cat 看小文件，less 看大文件和日志；grep 是在文字里钓鱼，man 和 --help 是随身说明书。
  • 报错要会读：No such file 是路径错了，Permission denied 是权限不够，Is a directory 是把文件夹当文件用了。
  • Tab 补全和方向键翻历史，现在就养成；下一课拆 ls -l，看权限到底是怎么回事。
