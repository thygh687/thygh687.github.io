模块六第 6 章：防火墙与入侵检测

网络安全基础2026-11-25 · 模块六

预备课第 15 课讲过防火墙的入门概念：墙，拦住不该进来的东西。这一章讲墙是怎么一代一代进化的，以及墙后面还需要什么样的哨兵。先把一句话放在前面：防火墙不是万能的，它只管进出，不管里面已经藏着的东西。木马是被人从邮件里请进来的，防火墙拦不住；内鬼从里面往外偷数据，防火墙也看不见。所以防火墙从来不是“装一个就安全了”，它是一套防线里的第一道。

防火墙的三代进化：从看信封到看内容

第一代：包过滤防火墙——只看信封。它检查每个数据包的“信封”：源地址、目标地址、端口、协议。规则写死了：比如“不许外网连我的 3389 端口”“只许内网访问数据库”。符合规则的放行，不符合的扔掉。优点是快、便宜、简单；缺点是笨——它不知道这个包属于哪次会话，也不知道包里装的是什么。攻击者把坏东西拆开放进“合法”的包里，它就看不出来了。

第二代：状态检测防火墙——记住会话。它在包过滤的基础上多记了一件事：这个包属于哪一次连接？模块三第 5 章讲过 TCP 握手：连接是先打招呼再传数据的。状态检测防火墙记着每一次连接的状态：外面来的包，如果不是里面先发起的会话的回包，直接扔掉。这样一来，攻击者想从外面主动连进来就难多了，因为墙上没有对应的会话记录。今天家用路由器、Windows 自带防火墙，基本都是这一代。

第三代：应用层防火墙——打开信封看内容。它能看懂应用层协议：这是 HTTP 请求吗？里面有没有 SQL 注入的语句？这是不是在传文件？应用层防火墙（常叫 WAF，专门守网站的那种）能拦住包过滤和状态检测都看不懂的攻击，比如往登录框里塞数据库命令。代价是慢、贵、配置复杂，而且 HTTPS 加密之后，内容看不到了——要解密才能检查，解密本身又带来新的管理问题。

下一代防火墙：墙长了眼睛和脑子

把上面三代的能力合在一起，再加上“认得出这是什么应用、这是谁在用”，就是下一代防火墙（NGFW）。它不只看端口，还看应用：同样走 443 端口，它能分清这是正常的网页浏览，还是有人在用网盘往外传文件；它不只看 IP，还看用户：同一个规则，对财务部和对实习生可以不一样。下一代防火墙还集成了入侵防御、病毒过滤、网址过滤，等于把好几件设备揉成了一件。

对初学者来说，记住下一代防火墙的两个关键变化就够了：从“按端口管”变成“按应用、按用户管”，以及从“单打独斗”变成“和其他安全设备联动”——发现可疑行为可以自动通知终端防护、自动封禁账号。下一代防火墙是企业网络的标配，但对个人用户来说，系统自带的状态检测防火墙加上良好的使用习惯，已经够用了，不用盲目追求。

IDS 与 IPS：哨兵和卫兵

防火墙管“让不让进”，入侵检测系统（IDS）管“进来的是不是坏人”。它像哨兵一样盯着流量，发现可疑的就报警，但自己不拦——报警之后，要不要处理，是人来决定。IDS 通常旁路部署：流量复制一份给它看，它不挡路，所以就算它自己出问题，也不会把网络搞断。

入侵防御系统（IPS）是 IDS 的升级版：它串联在流量的必经之路上，看见攻击就直接拦下来，不用等人工处理。好处是反应快，坏处是：一旦它判断错了，会把正常业务也拦掉；一旦它自己出故障，整条路就断了。所以 IPS 的部署要比 IDS 谨慎得多，规则要调得准。

IDS/IPS 认攻击有两种方法。签名检测：像查通缉令——把流量的特征和已知攻击的特征库比对，对上了就报警。优点是准、误报少；缺点是只认得见过的攻击，新攻击、变种攻击认不出来。异常检测：先学出“正常长什么样”，再看谁偏离了正常：平时凌晨三点没人登录，今天突然有人凌晨三点从境外登录，那就是异常。优点是能发现没见过的新攻击；缺点是误报多——业务一变、员工一出差，正常行为也可能被当成异常。

误报（False Positive）和漏报（False Negative）是 IDS/IPS 永远的矛盾：规则调得严，误报多，安全团队被报警淹没，真的攻击反而淹没在报警里没人看；规则调得松，漏报多，攻击溜过去了都没人知道。调规则、看报警、处理报警，是安全运营每天的日常工作，也是下一章要讲的 EDR/XDR 想要解决的问题。

EDR/XDR 是什么：从守门口到盯着每个人

防火墙守的是网络的门口，IDS/IPS 盯的是路上的流量，但攻击者一旦进了门、上了某台电脑，门口的哨兵就看不见他了。EDR（终端检测与响应）就是装在每台电脑上的哨兵：它盯着这台电脑上发生的事——哪个程序启动了、改了什么文件、连了哪个地址、输了什么命令，发现可疑行为就报警、甚至直接隔离。杀毒软件看“文件是不是已知的坏东西”，EDR 看“行为是不是像攻击”：第 3 章讲过，攻击者爱用系统自带的合法工具，文件查不出来，行为却藏不住。

XDR（扩展检测与响应）是 EDR 的扩大版：它把终端、网络、邮件、云上、身份系统的数据打通，拼成一张完整的图。攻击者在邮件里钓鱼、终端上运行木马、内网里横向移动——单看任何一个点都可能觉得“还好”，拼在一起就是一次完整的入侵。XDR 的价值就是“拼图”：让安全团队看到全貌，而不是一个个孤立的报警。EDR 和 XDR 的具体工作方式，第 7 章会展开讲。

老师经验：我见过最常见的防火墙事故，不是被攻破，而是被自己人配错了：一条规则写错，全公司上不了网；一条放行规则写得太宽，等于墙上开了个大洞。现场排错时，我的第一步永远是“看规则、看日志”，而不是“重启设备”。还有一次，客户的 IDS 一天报几千条告警，没人看得过来，等于没装。我帮他们做的第一件事不是加设备，而是把告警分级：能确认是攻击的立刻处理，疑似的每天汇总看一次，明显是误报的调规则消掉。记住：安全设备买回来只是开始，规则调优和告警处理才是它真正产生价值的地方。一台没人看、没人调的 IDS，和没装没有区别。

动手做

只在虚拟机或自己的实验环境里做，不要碰真实网站、真实网络，不要扫描别人的地址。
1. 在自己的 Windows 电脑上打开 Windows Defender 防火墙的高级设置，看一看入站规则和出站规则：哪些程序被允许通过？有没有你不认识的规则？只看、不改——想改规则，先在虚拟机里练。
2. 在虚拟机里装一个 Linux 系统，打开它的防火墙（比如 ufw），练习两条命令：sudo ufw status 看当前状态，sudo ufw allow 22/tcp 放行 SSH。再想一想：这条规则对应的是本章讲的哪一代防火墙能力？
3. 在虚拟机里，用 ss -tln（Linux）或 netstat -an（Windows）列出本机正在监听的端口。对照模块三第 10 章的常用端口表，认一认每个端口是哪个服务在监听。有没有你不认识的监听端口？记下来，查公开资料确认它是什么。
4. 画一张你家或你宿舍的网络拓扑草图：光猫、路由器、电脑、手机都在哪儿？防火墙在哪一层？如果攻击者想进来，要过几道关？这张图就是你家网络的“城防图”。

避坑

别以为装了防火墙就安全了：防火墙只管进出，管不住钓鱼邮件请进来的木马，也管不住内鬼；别把防火墙规则写得太宽：放行“所有端口”等于没装墙，规则要精确到端口、到地址、到应用；别把 IDS 的告警当摆设：没人看、没人处理的告警系统等于没装，告警要分级、要有人负责；别分不清 IDS 和 IPS：IDS 只报警不拦，IPS 会直接拦——把 IPS 的规则调得太严，会把正常业务也拦掉；别在真实网络上扫端口、试规则：所有实验都在虚拟机和自己的本地网络里做，只扫 127.0.0.1 和自己的虚拟机；别忘了防火墙自己也要保护：管理口令要强、管理地址要限制，防火墙被攻破比没装更糟。

守住了门口和路上，下一章守每一台电脑和每一个邮箱：第 7 章：终端与邮件安全：EDR、XDR 与 DLP——EDR 怎么盯着终端、XDR 怎么把数据打通、DLP 怎么防数据外泄。回头看模块三第 5 章的 TCP 与端口：防火墙规则里写的端口号，就是那一章讲的门牌号。

本课小结
  • 防火墙三代：包过滤（只看信封）、状态检测（记住会话）、应用层（打开信封看内容）；下一代防火墙按应用、按用户管，还能和其他设备联动。
  • IDS 是哨兵：旁路监听、只报警不拦；IPS 是卫兵：串联在路上、看见攻击直接拦，配错了会误伤正常业务。
  • 检测两种方法：签名检测认已知攻击、准但认不出新的；异常检测认偏离正常的、能发现新攻击但误报多。
  • 误报太多会把真攻击淹没，漏报太多等于没防住；调规则、看告警、处理告警，是安全运营的日常。
  • EDR 盯着每台终端的行为，XDR 把终端、网络、邮件、云的数据拼成一张完整的图。
