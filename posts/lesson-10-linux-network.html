第 10 课：Linux 下的网络命令

Linux2026-11-24 · 阶段二

Windows 下的 ping、ipconfig 到了 Linux 里，名字换了，干的活一样。记住这四个。

ping：通不通

ping example.org，跟 Windows 里一样。注意 Linux 的 ping 默认一直发，按 Ctrl + C 停下来。

ip a：看本机网络配置

ip a 相当于 Windows 的 ipconfig，看自己的 IP 地址和网卡。

curl：发个请求看返回

curl example.org 会把那个网页的 HTML 直接打出来。加 -I 只看响应头，包括状态码。

ss：谁在监听端口

ss -tlnp 列出本机正在监听的端口和对应的程序。这是以后查“这台机器开了什么服务”的基本功。

动手做

在虚拟机里跑一遍：curl example.org 看返回；ss -tlnp 看本机开了哪些端口，记下来。
