模块一第 11 章：计算机是怎么启动的

组成原理2026-11-24 · 模块一

按下电源键到看见桌面，中间经过了一串步骤。弄清楚这个过程，以后电脑开不了机，你就知道该从哪一步开始查——启动链上的每一步都有自己的“死法”，症状不一样，查的方向也不一样。

启动流程

通电后，CPU 先执行主板上一块只读芯片里的固件（BIOS 或 UEFI），固件做自检：检查 CPU、内存、硬盘这些硬件在不在、好不好。然后固件按启动顺序找启动设备（一般是硬盘），从硬盘上加载引导程序，引导程序再加载操作系统内核，内核接管硬件、启动各种服务，最后出现登录界面。

展开说，第一步通电自检（POST）里还有个关键细节：内存训练。固件要先测出内存条能不能稳定工作，测不过就直接停在这里，连画面都没有——很多“开机黑屏、风扇转几下就停”的故障，根子就是内存条没插好或坏了。固件找到启动设备后，读的是硬盘最开头的一小段引导代码，它再去找真正的引导程序；引导程序读操作系统的内核文件，把控制权交给内核；内核起来之后挂载硬盘、加载驱动、启动服务，最后才轮到登录界面。整条链是“前一步交给后一步”，任何一步断掉，后面的都不会发生。

BIOS 和 UEFI

BIOS 是老一代固件，UEFI 是新一代。现在的新电脑基本都是 UEFI：支持 2TB 以上的大硬盘启动，有图形界面，启动更快。UEFI 还有一个重要功能叫安全启动（Secure Boot）：只允许经过签名的操作系统启动，防止 rootkit 这类底层恶意软件在系统启动之前就偷偷加载。

两者最实在的区别在分区表上：BIOS 配 MBR 分区表，启动盘最大只认 2TB；UEFI 配 GPT 分区表，多大都认得。装系统时“这个盘装不上”的报错，十有八九就是固件和分区表没配对——UEFI 的机器拿 MBR 盘去装，或者 BIOS 的机器拿 GPT 盘去装，都会被拒绝。另外 UEFI 启动时固件本身就能读硬盘上的文件（比如 EFI 分区里的引导文件），而 BIOS 只能读硬盘最开头的 512 字节——这就是为什么 UEFI 启动更快、功能更多。

启动管理器：开机后谁决定进哪个系统

固件找到启动设备之后，并不是直接进系统——中间还有一位“管进门的”：启动管理器。它的工作就是决定进哪个系统：机器上只装了一个系统，它就直接把那个系统加载起来；装了两个系统（比如 Windows 和 Linux 双系统），开机时出现的那张选择菜单，就是启动管理器画出来的，你选哪个，它就加载哪个系统的内核。

Linux 上最常见的是 GRUB：开机出现系统列表，选 Linux 还是 Windows，由它说了算，选好之后它再去加载对应系统的内核。Windows 用的是 Windows 启动管理器（Windows Boot Manager），它读一份叫 BCD 的启动配置数据（Boot Configuration Data）来做决定：BCD 里记着装了哪些系统、每个系统从哪里启动、要不要显示选择菜单、等几秒自动进默认系统。BCD 就像一张“菜单加规则”的清单，启动管理器照着清单办事——清单改错了，启动管理器就找不到系统，机器也就开不了机。

所以开机后进哪个系统，不是固件说了算，也不是硬盘说了算，而是启动管理器对照 BCD 说了算。固件只负责把启动管理器找出来、交出控制权，后面的选择权都在启动管理器手里。内核接管之后，Windows 内部又是怎么分层的，可以去看课程目录里的 Windows 专项，第 1 章 Windows 架构：NT Executive、内核与 HAL就是讲那张分层地图的。

EFI 系统分区（ESP）：启动文件住在哪

EFI 系统分区（ESP，EFI System Partition）是硬盘上一个很小的 FAT32 分区，一般只有 100 到 500MB，里面住着启动管理器和启动文件。UEFI 启动时不是把整个系统盘翻一遍，而是直接去读这个分区里的文件，找到启动管理器就把控制权交过去——这就是前面说的“UEFI 固件本身就能读硬盘上的文件”。

记住两点就够了：第一，ESP 里没有你的个人文件，平时不用去动它，重装系统时安装程序会自己建好它；第二，ESP 删不得、格式化不得——删了它，UEFI 就找不到启动管理器，机器直接开不了机，很多“重装分区时手滑删了个小分区，结果开不了机”的故障，删掉的正是它。

安全启动与信任链：防的是启动之前的攻击

安全启动的思路是一条信任链：固件里存着厂商的公钥，只放行用对应私钥签过名的引导程序；引导程序再只放行签过名的内核；内核再只加载签过名的驱动。一环扣一环，任何一环没签名或签名不对，启动就停在那里。它防的是一类叫 bootkit（引导区病毒）的东西：这种恶意软件藏在操作系统“下面”的引导环节，普通杀毒软件在系统里根本看不到它，重装系统也清不掉它——因为它不在系统分区里，而在引导区。

信任链也不是万无一失：签名用的私钥一旦泄露，攻击者就能给恶意引导程序签上名；有些电脑出厂时安全启动是关着的；还有一种叫“测量启动”的技术（配合 TPM 芯片），把每一步的哈希值记下来，启动后可以检查有没有哪一步被改过——这是更进一步的防护，知道有这回事就行。现阶段记住结论就够了：安全启动是防底层恶意软件的一道门，平时别随手关掉它；如果一台电脑重装系统后病毒还在，先怀疑引导区和 EFI 分区，而不是怀疑系统装得不干净。

安全启动之外，还有一颗专门管安全的芯片：TPM 2.0（可信平台模块）。它是一颗焊在主板上的小安全芯片，专门做两件事：存密钥——密钥放在芯片里，算出来的东西出芯片，但密钥本身不出芯片；量启动——配合下面说的度量启动，把启动过程的每一环量一遍再放行。

度量启动（Measured Boot）的做法是：启动链上的每一环——固件、启动管理器、内核、驱动——在加载之前先算一个哈希值（可以理解成这一环内容的“指纹”），把指纹记进 TPM 里。启动完成后，系统可以拿这些指纹和正常的指纹对照，检查有没有哪一环被偷偷改过。和安全启动的区别要分清：安全启动是“签名不对就当场拦下”，度量启动是“每一步都量一遍、留个记录备查”，一个管放行，一个管留证，两者配合，启动过程才既有门又有账。

这三件套现在是硬要求：Windows 11 要求 UEFI + 安全启动 + TPM 2.0，缺一件都装不上、升不了级。这不是微软随手定的门槛，而是把启动安全从“建议打开”变成了“必须具备”——机器出厂时这三样齐了，底层的 bootkit 才更难有立足之地。

开不了机怎么查

按启动流程倒着查：电源灯亮不亮（电源和主板），有没有自检画面（固件），报不报错（比如找不到启动设备就是硬盘或引导的问题），卡在哪个画面（Windows 转圈就是系统的问题）。知道流程，排查就有了顺序，而不是乱试。

按图里的顺序对号入座：完全没反应，先查电源线、插座、电源开关，台式机再看主板上的指示灯；风扇转但黑屏无画面，优先怀疑内存条（重新插拔一根试试）和显卡；出现主板 logo 但提示找不到启动设备，查硬盘线有没有松、启动顺序是不是被改了、硬盘本身坏没坏；能进引导但反复重启或蓝屏，问题在引导程序或系统文件，可以进安全模式或用安装 U 盘修复引导；卡在登录界面进不去、输对密码又弹回来，多半是系统服务或用户配置损坏，和硬件关系不大。每一类症状都有自己的查法，乱试只会越修越糟。

如果问题出在启动链的后半段（引导程序或系统文件），先别急着重装，走官方恢复环境的思路：Windows 连续启动失败几次，会自动进 Windows 恢复环境（WinRE），也可以用官方安装 U 盘进恢复环境；里面有个“启动修复”，它会自动检查并修常见的启动问题——先让它修一遍，很多引导损坏到这里就解决了。进恢复环境的办法要记牢：它不靠系统本身能启动，而是靠恢复分区或安装 U 盘，所以系统起不来时它还能用。

启动修复修不好，再按顺序往下想：先确认启动顺序对不对（是不是 U 盘顶掉了原来的硬盘、硬盘还在不在启动列表里），再确认 EFI 系统分区和启动文件还在不在，最后才怀疑 BCD 坏了。BCD 重建的思路是：让恢复环境里的工具按磁盘上真实装着的系统，重新生成一份启动配置——恢复环境里有名为 bootrec 的命令行工具可以做这件事，具体操作跟官方文档走，不要在没把握的真机上练手。整个修启动的原则是只修“启动链断了”，绝不绕安全机制：不教关安全启动、不教绕 TPM、不教绕登录密码，修的是启动，不是拆防护。

老师经验：修电脑遇到开不了机，先问客户三个问题：灯亮不亮、有没有画面、卡在哪一步——三个答案一对，故障范围就缩到启动链的某一段里了，远程指导也一样管用。另外记住一条：重装系统之后病毒还在，别再重装第二遍了，先查 EFI 分区和引导区有没有被动过手脚；还有，帮别人装系统之前先看一眼 BIOS 模式是 UEFI 还是传统，分区表配不对，装到一半报错，白白浪费一趟时间。

动手做

1. 按 Win+R，输入 msinfo32 回车，看“BIOS 模式”那一行，是 UEFI 还是传统。
2. 再看“系统型号”“处理器”“安装的物理内存”，对照第 12 章的体检报告。
3. 开机时留意主板 logo 画面（别乱进 BIOS 改东西，先只看）。
4. 只在虚拟机里：打开虚拟机的磁盘管理，看一眼有没有一个 FAT32 的小分区（EFI 系统分区），再对照本课的启动链图，说一说 UEFI 是怎么靠它找到启动管理器的；只看不动手，别删、别格式化。

避坑

BIOS 里别乱改不认识的选项，改错了可能开不了机；改启动顺序前先知道自己在干什么；安全启动别随便关，它是防底层恶意软件的一道门。补充两点：进 BIOS 改设置之前，先拍张照记下原来的值，改坏了还能改回来；“找不到启动设备”先别急着断定硬盘坏了——很多时候只是启动顺序被 U 盘顶掉了，拔掉 U 盘重启就好了。

别删 EFI 系统分区，也别格式化它——删了它，UEFI 就找不到启动管理器，机器直接开不了机；BCD 和启动文件也别手动乱改，改错了同样开不了机，要练先在虚拟机里练，出了问题走官方恢复环境修。

本课小结
  • 启动是一条链：通电自检 → 固件 → 找启动设备 → 引导程序 → 内核接管 → 服务与登录；哪一步断掉，后面的都不会发生。
  • UEFI 是新一代固件，配 GPT 分区表，认得 2TB 以上的启动盘，启动更快；BIOS 配 MBR，启动盘最大 2TB。
  • 安全启动是一条信任链：固件只放行签过名的引导程序，防的是藏在系统下面的 bootkit；重装系统清不掉的病毒，先怀疑引导区。
  • 启动管理器决定进哪个系统：Linux 常见 GRUB，Windows 用 Windows 启动管理器读 BCD 做决定；UEFI 靠读 FAT32 的 EFI 系统分区（ESP）找到启动管理器，ESP 删不得。
  • Windows 11 要求 UEFI + 安全启动 + TPM 2.0 三件套；度量启动把启动的每一环量一遍、把指纹记进 TPM，安全启动管放行，度量启动管留证。
  • 开不了机按症状定位到某一步再查：没反应查电源，黑屏查内存和显卡，找不到启动设备查硬盘和启动顺序，蓝屏和转圈查系统。
