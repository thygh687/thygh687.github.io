模块一第 1 章：二进制与数据表示

组成原理2026-11-24 · 模块一

电脑里只有两种状态：晶体管导通、有电，是 1；断开、没电，是 0。一位这样的数叫 bit，8 位叫一个 byte。电脑里的一切——数字、文字、图片、声音——最后都是 0 和 1 的排列。

二进制和十进制一个道理

十进制里，263 是 2 个一百、6 个十、3 个一，每一位是 10 的倍数。二进制也一样，只是每一位是 2 的倍数：101 就是 1 个四、0 个二、1 个一，加起来是 5。再比如 10110111：1×128 + 0×64 + 1×32 + 1×16 + 0×8 + 1×4 + 1×2 + 1×1 = 183。

负数怎么存：补码

电脑里负数用补码存。8 位数里，-3 的补码是 11111101（十进制 253）。好处是加减法能用同一套电路算：5 + (-3) 就是 5 + 253 = 258，超过 8 位的进位丢掉，得 2，答案是对的。你先会用就行，推导过程以后再看。

小数和文字

小数用浮点数存（IEEE 754 标准），由符号位、指数和尾数三部分组成，精度有限，所以 0.1 + 0.2 在电脑里不等于 0.3——这是正常的，不是 bug。文字也是数字：编码表规定每个字符对应哪个数字，ASCII 里大写 A 是 65；中文用 UTF-8，一个汉字一般占 3 个字节。

容量单位

1 KB 是 1024 个字节，1 MB 是 1024 KB，1 GB 是 1024 MB，1 TB 是 1024 GB。买硬盘时说的 500GB，电脑里显示会少一点，是因为厂家按 1000 算，电脑按 1024 算。

视频讲解：Representing Numbers and Letters with Binary — Crash Course Computer Science #4（YouTube，英文，可开自动字幕，约 11 分钟）

动手做

1. 打开 Windows 计算器 → 左上角菜单 → 程序员，在十进制和二进制之间切换，输几个数看它们怎么互相转换。
2. 新建一个记事本，输入一个字母 A 保存，看文件大小是 1 字节；再输入一个汉字“中”保存，看文件大小是 3 字节。
3. 算一算：二进制 1100100 是多少？（答案：100。）

避坑

别背二进制表，重点是理解“每一位是 2 的倍数”这个道理；补码先会用，不用死磕推导；容量单位记住 1024 就够了，不用纠结硬盘标称和实际显示差多少。
