模块七小结：从看懂网站到合法找漏洞

小结2026-11-25 · 模块七第 1–29 章

二十九章讲的其实是一条线，顺序不能反：先看懂网站是怎么工作的，再学会怎么找漏洞，最后学会怎么合法地做一次完整的测试。前半部分在讲“看懂”——请求、响应、会话、注入、跨站；中间在讲“打进去”——扫描、利用、提权、后渗透；后半部分在讲“打得深、守得住、做得对”——活动目录、API、开发流程、无线、方法论与法律边界。最后一章把这些本事合起来，变成一份能交出去的渗透测试报告。

这二十九章是怎么连起来的

先看懂网站。第 1 章 Web 工作原理深入讲了请求、响应、会话与 Cookie——网站是怎么工作的，先会模块四第 9 章的 HTML/JS 再来学。第 2 章 SQL 注入实战从原理到利用，原理在模块五第 4 章。第 3 章 XSS 跨站脚本，让别人的浏览器替你干活。第 4 章 CSRF 与 SSRF，借刀杀人的两种方式（2025 版 OWASP 已把 SSRF 并入 A01）。第 5 章文件上传与逻辑漏洞，不止是技术漏洞。第 6 章 XXE 与反序列化，容易忽略的两类漏洞。第 7 章会话与认证深入：JWT、CORS、CSP 与越权访问，Web 认证的攻与防。

然后是打进去的工具与手法。第 8 章信息收集与扫描进阶：Nmap、漏洞扫描、OSINT。第 9 章 Nmap 与扫描深入，扫描的艺术。第 10 章 Burp Suite 深入，抓包改包的神器怎么用。第 11 章漏洞利用工具链：Metasploit、Burp、密码攻击、持久化与横向移动。第 12 章 Metasploit 深入，漏洞利用框架怎么用。第 13 章 Linux 提权，Linux 系统的提权手法。第 14 章 Windows 提权，Windows 系统的提权手法。第 15 章后渗透与报告：拿到权限之后干什么——收集信息、横向移动、写报告。

再往深处打。第 16 章绕过与持久化：免杀、持久化机制与 C2——躲过检测、留住权限，防御靠纵深防御。第 17 章动手搭一个活动目录实验环境：自己的域控实验室，域控加两台客户端，网络与真实网络隔离。第 18 章活动目录基础：企业内网的骨架——域、域控、OU、组、GPO、Kerberos 三步拿票。第 19 章活动目录攻击：票据、哈希传递、BloodHound——从普通账号爬到域管理员的四台阶。第 20 章活动目录防御与加固：分层管理、凭据保护、收拾权限、监控告警，怎么守住域控。第 21 章活动目录攻击进阶：黄金票据、白银票据、横向移动、无约束委派、NTLM 中继、DCSync。

然后换一个战场。第 22 章 API 安全：OWASP API Top 10——接口才是现在的主战场，BOLA 是头号杀手。第 23 章 API 安全深入：GraphQL 与 JWT 攻击——内省、深度查询、alg none、弱密钥、kid 与 jku 注入。第 24 章安全开发生命周期 DevSecOps：SAST、DAST、SCA、IaC 四种扫描，安全要进开发流程。第 25 章无线渗透：Wi-Fi 实战，只针对自己的路由器和实验环境——WPA3、PMF、长随机密码。

最后是做得对。第 26 章动手按 OWASP Top 10 2025 版逐条过：A01 到 A10，每条四步——理解原理、找到入口、验证影响、想好修复。第 27 章渗透测试方法论：七个阶段，从约定范围到复测闭环。第 28 章法律与道德边界：书面授权是唯一标准，三条红线绝不能碰；Security+ 当前版本是 SY0-801，CISP 是国内认证。第 29 章是模块七的结课实战：五个战场、七个阶段，一次完整的渗透测试，一份能交出去的报告。

现在你能做什么

  • 说清一个网站是怎么工作的：请求、响应、会话、Cookie，再讲清 SQL 注入、XSS、CSRF、SSRF 是怎么发生的。
  • 用 Nmap、Burp Suite、Metasploit 走完一次扫描到利用的流程，并在自己的靶场里验证 Linux 与 Windows 提权。
  • 搭出自己的活动目录实验环境，用 BloodHound 画出从普通用户到域管理员的攻击路径，再按分层与凭据保护的思路堵上它。
  • 按 OWASP API Top 10 测接口：用两个账号交叉测 BOLA 与 BFLA，验一遍 JWT 的签名，查 GraphQL 的内省与深度限制。
  • 按 OWASP Top 10 2025 版逐条检查一个靶场：每条写清入口、验证结果与修复办法。
  • 按七个阶段做一次完整的渗透测试：先写授权书、再动手，最后交出一份带证据、带定级、带修复步骤的报告，并复测闭环。
  • 守住边界：只在自己的实验环境里动手，只认书面授权，测试结束清理干净——技术越强，边界感越重要。

下一步

模块八，安全运营与应急响应。角色从攻击方换成防守方：蓝队的工作——盯着、发现、出事之后怎么办。模块七的本事会一直跟着你：你知道攻击者从哪来、走哪条路、会在哪一步被拦住，所以你也知道监控该盯哪里、告警该怎么设、应急响应该先做什么。去之前，先把第 29 章的渗透测试报告收好——那是你第二份真正的安全工作成果，第一份是模块六的评估报告。
