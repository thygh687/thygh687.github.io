模块一第 3 章：存储器：内存、缓存、硬盘

组成原理2026-11-24 · 模块一

存储器是个金字塔：越靠近 CPU 越快、越小、越贵；越远离越慢、越大、越便宜。电脑就是在这个取舍里工作的。这一章要讲清楚每一层为什么存在、数据是怎么在各层之间搬的、以及“断电丢不丢”这条线为什么是安全上最重要的一条分界。

为什么非得有这么多层

CPU 一秒能算几十亿次，但内存一次读写要上百个时钟周期——CPU 等内存，就像大脑等一个慢吞吞的仓库管理员。如果只有内存这一层，CPU 大部分时间都在等，性能全浪费在等待上。办法是加几层“小抄”：把最常用的数据放在离 CPU 最近的地方，命中了就不用跑远路。这就是缓存存在的全部理由：不是为了存更多东西，而是为了让 CPU 少等。

反过来问：为什么不全用最快的？因为快的东西贵、做不大。寄存器用触发器做，一个 bit 要好几个晶体管；内存用一个晶体管加一个电容存一个 bit，便宜得多，但电容会漏电，要不停刷新；硬盘用磁性或闪存存，断电也不丢，但慢得多。每一层都是速度、容量、价格、断电丢不丢这四件事的取舍，没有一层是完美的。

每一层是干什么的

寄存器在 CPU 里面，容量只有几十个字节，速度最快，放正在算的数据。缓存分 L1、L2、L3，离 CPU 越近越快越小，是 CPU 身边的小抄，常用的东西放这里，省得老跑内存去拿。内存是工作台，正在运行的程序和数据都在这里，断电就清空；内存越大，能同时摊开的东西越多，电脑越不容易卡。硬盘是仓库，长期保存文件，断电也不丢。

缓存是怎么工作的：命中与未命中

CPU 要一个数据，先问 L1 有没有：有，叫命中，几个周期就拿到；没有，叫未命中，再问 L2、L3，最后才去内存。每一级未命中都要多等一截，所以程序跑得快不快，很大程度上看命中率高不高。命中率高不高，又取决于程序访问数据的规律——这就是第 8 章要讲的局部性：刚用过的数据、挨着的数据，很可能马上还要用。缓存就是赌这个规律：把刚用过的和挨着的一块搬进来，赌它马上还要用。缓存到底按什么规则决定换谁进来、换谁出去（直接映射、组相联、全相联，替换算法和写策略），是第 18 章：Cache 深入的事。

还有两个细节值得知道。第一，缓存搬数据是按“行”搬的，一次搬一块（通常 64 字节），不是一个字节一个字节搬——所以挨着的数据沾光。第二，数据改了怎么办？写回缓存后，要不要马上写回内存？马上写叫直写，简单但慢；先记着、等缓存行被换出去时再写，叫写回，快但复杂，断电时没写回的数据会丢。这就是为什么突然断电可能丢数据：改过的数据可能还只在缓存里，没落到硬盘上。

速度差多少：等硬盘是最贵的等

寄存器基本 1 个时钟周期就能拿到数据，缓存几个到几十个周期，内存要上百个周期，硬盘要几毫秒——是内存的上万倍。所以电脑慢，很多时候是卡在等硬盘上，而不是 CPU 不够快。一个形象的对比：如果 CPU 一拍是一秒，寄存器就是伸手就能拿到的抽屉，缓存是隔壁房间，内存是楼下仓库，硬盘是城外的货场。程序员和系统优化，做的事大半就是“少跑货场，多用抽屉”。

内存：DDR、双通道与“够用就行”

现在主流是 DDR4、DDR5，数字只是代数，新一代速度更快。内存是 DRAM，一个 bit 一个电容，电容漏电，所以要不停刷新——刷新的时候不能读写，这也是内存比缓存慢的原因之一。两条一样的内存插在一起能开双通道，带宽翻倍：不是容量翻倍，是路宽了一倍。内存不是越大越好，够用就行：日常办公 16GB 足够，玩大型游戏或开虚拟机再考虑 32GB。你的电脑是 64GB，工作台很大，同时开几十个程序也不容易满——但这不等于不会卡：内存满了，系统会把不用的东西挪到硬盘上的页面文件里（虚拟内存，模块二第 7 章会讲），一挪就慢下来了。

什么时候加内存，什么时候换硬盘？任务管理器里内存占用长期 90% 以上，加内存；内存还剩一半、磁盘占用却老是 100%，换 SSD。两个都满，先加内存还是先换硬盘，看哪个先到瓶颈——别凭感觉，先看数字。

硬盘：机械盘和 SSD，删了的东西去哪了

机械硬盘（HDD）靠磁头在盘片上读写，便宜、容量大；固态硬盘（SSD）是闪存芯片，没有机械部件，快得多。接口也有讲究：NVMe 的 SSD 比 SATA 的更快。系统盘用 SSD，体验差很多。SSD 还有个特点：闪存格子写多了会坏，所以它内部会均匀分摊写入（磨损均衡），删掉的东西也不一定马上真没了。RAID 是怎么把几块盘拼成又快又稳的、SSD 里面到底是怎么存的，是第 24 章：存储进阶的事。

安全上最要紧的一点：删掉的文件不是真没了。操作系统删文件时，通常只是把目录里的记录划掉、把占用的位置标记为空，数据本身还躺在盘上，直到被新数据覆盖——这就是取证能恢复“已删除”文件的原因。SSD 上情况更复杂：TRIM 命令会告诉 SSD 哪些块不用了，SSD 可能在后台真的擦掉它们，所以 SSD 上的删除比机械盘更难恢复，但也不是“删了就一定没了”。结论只有一个：想让数据真的消失，删文件不够，要专门做安全擦除或加密后丢掉密钥。

断电丢不丢：安全上的分界线

寄存器、缓存、内存是易失的：断电就清空。硬盘是非易失的：断电也不丢。这条线决定了很多安全问题的答案：密码、密钥、解密后的文件明文，正在用的时候都在内存里——电脑一断电、进程一退出，内存里的东西就没了；但只要电脑还开着、程序还在跑，内存里就躺着明文。这就是内存取证的原理，也是“锁屏了就安全吗”这个问题的答案：锁屏只挡住了屏幕，内存里的东西还在，有办法读到内存的人，照样能拿到。反过来，硬盘上的东西要靠加密保护：不加密的硬盘，拆下来接到别的电脑上就能直接读。第 11 章讲启动时会再回到这个问题：从开机那一刻起，数据是怎么一层层从硬盘搬进内存的。

还有一个常被忽略的角落：缓存本身也会“说话”。第 2 章提过，推测执行访问过的数据会留在缓存里，攻击者通过测“访问某个地址快还是慢”，就能推断出数据在不在缓存里，进而一点点把数据猜出来。这就是缓存侧信道攻击——缓存本是用来加速的，却成了泄密的渠道。速度和安全，在这里是直接冲突的。

老师经验：修电脑先分清“丢没丢”：用户说文件没了，先问是没保存（那在内存里，断电就真没了，神仙也救不回来），还是删了（那在硬盘上，还有机会恢复，别再往盘里写东西，越写覆盖得越多）。内存取证我也常遇到：机器还开着，先别急着关机——内存里可能正躺着没保存的文档、刚输过的密码、解密后的文件，关机就全没了；先做内存转储，再关机。反过来，缴获的机器如果已经关机，就别指望内存里还有东西，直接从硬盘和日志入手。还有一条：SSD 换下来别直接扔，闪存里的数据不一定擦得干净，重要盘先加密、再处理。

动手做

1. 打开任务管理器 → 性能，看内存是多大的、用掉多少、速度是多少。
2. 看磁盘那一栏，确认自己的硬盘是 SSD 还是 HDD。
3. 复制一个大文件，看磁盘读写速度的变化；再打开一个占内存大的程序，看内存占用怎么涨。

避坑

电脑卡先看任务管理器是内存满了还是磁盘满了，对症下药；别乱装“内存优化”软件，多数是摆设；换 SSD 是让旧电脑变快最有效的一招，比加内存往往更明显；最容易错的两个观念：以为删了文件就真没了，以及以为锁屏了内存里就没东西了——两个都错。

下一章，数据终于要“动手”了：第 4 章汇编入门，你会亲手写 CPU 真正执行的指令。回头看第 2 章的取指循环，想想每条汇编指令是怎么走完那四步的。

本课小结
  • 存储器是金字塔：越靠近 CPU 越快越小越贵，缓存的存在是为了让 CPU 少等内存。
  • 缓存按行搬数据，命中就快、未命中就一层层往下找；改过的数据不一定马上写回硬盘，断电可能丢。
  • 内存是 DRAM，断电清空；硬盘是非易失的，断电不丢——这条线是安全上的分界线。
  • 删文件只是划掉记录，数据还在盘上；想让数据真消失，要安全擦除或加密后丢密钥。
  • 缓存也会泄密：推测执行留下的缓存痕迹，能被侧信道攻击一点点读出来。
