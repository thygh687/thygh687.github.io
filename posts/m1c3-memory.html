模块一第 3 章：存储器：内存、缓存、硬盘

组成原理2026-11-24 · 模块一

存储器是个金字塔：越靠近 CPU 越快、越小、越贵；越远离越慢、越大、越便宜。电脑就是在这个取舍里工作的。

每一层是干什么的

寄存器在 CPU 里面，容量只有几十个字节，速度最快，放正在算的数据。缓存分 L1、L2、L3，离 CPU 越近越快越小，是 CPU 身边的小抄，常用的东西放这里，省得老跑内存去拿。内存是工作台，正在运行的程序和数据都在这里，断电就清空；内存越大，能同时摊开的东西越多，电脑越不容易卡。硬盘是仓库，长期保存文件，断电也不丢。

速度差多少

寄存器基本 1 个时钟周期就能拿到数据，缓存几个到几十个周期，内存要上百个周期，硬盘要几毫秒——是内存的上万倍。所以电脑慢，很多时候是卡在等硬盘上，而不是 CPU 不够快。

内存：DDR 和双通道

现在主流是 DDR4、DDR5，数字只是代数，新一代速度更快。两条一样的内存插在一起能开双通道，带宽翻倍。内存不是越大越好，够用就行：日常办公 16GB 足够，玩大型游戏或开虚拟机再考虑 32GB。

硬盘：机械盘和 SSD

机械硬盘（HDD）靠磁头在盘片上读写，便宜、容量大；固态硬盘（SSD）是闪存芯片，没有机械部件，快得多。接口也有讲究：NVMe 的 SSD 比 SATA 的更快。系统盘用 SSD，体验差很多。

动手做

1. 打开任务管理器 → 性能，看内存是多大的、用掉多少、速度是多少。
2. 看磁盘那一栏，确认自己的硬盘是 SSD 还是 HDD。
3. 复制一个大文件，看磁盘读写速度的变化。

避坑

电脑卡先看任务管理器是内存满了还是磁盘满了，对症下药；别乱装“内存优化”软件，多数是摆设；换 SSD 是让旧电脑变快最有效的一招，比加内存往往更明显。
