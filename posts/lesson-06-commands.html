第 6 课：动手：ping、ipconfig、nslookup

动手2026-11-24 · 阶段一

前面五课的概念，用这三个命令一次验证完。先按 Win + R，输入 cmd 回车，打开命令行。

ping：对方在不在，要多久

ping example.org

发个小包过去问一声。返回的时间就是延迟，一般几十毫秒。超时或者全部丢失，说明这条路不通。

ipconfig：看本机的网络配置

ipconfig

看自己的 IPv4 地址、子网掩码、默认网关和 DNS 服务器。第 3 课的四个概念，一条命令全看到了。

nslookup：问 DNS 要地址

nslookup example.org

直接问 DNS 服务器：这个域名对应哪个 IP。返回的地址应该和 ping 显示的那个一致。

排错思路

上不了网的时候，按这个顺序查：先 ping 网关（家里网络通不通），再 ping 外网地址（能上网吗），最后 nslookup（是不是 DNS 的问题）。一步一步缩小范围。

动手做

三条命令各跑一遍，把结果记下来：你的 IP 是多少，网关是多少，example.org 的 IP 是多少。
