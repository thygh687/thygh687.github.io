模块一第 5 章：总线与输入输出

组成原理2026-11-24 · 模块一

CPU、内存、硬盘、显卡之间要传数据，走的都是总线。总线就是电脑里的路，路越宽、一次能运的东西越多。

输入输出设备

键盘、鼠标、显示器、网卡、硬盘都是输入输出设备。CPU 通过端口跟它们打交道：往端口写数据就是发命令，从端口读数据就是收结果。

中断

设备有事的时候会打断 CPU 一下：比如你敲了一个键，键盘就发个中断，CPU 停下手里的活，先处理这个按键，再回去继续。中断让 CPU 不用一直盯着设备问“有事吗”，有事设备自己会说。

DMA

大块数据搬运（比如从硬盘读一个大文件）不用 CPU 一点一点盯着，DMA 控制器直接在内存和硬盘之间搬，搬完告诉 CPU 一声就行。省下来的 CPU 时间可以干别的。

动手做

右键“此电脑” → 管理 → 设备管理器，看一眼自己电脑的设备：处理器、磁盘驱动器、网络适配器都在。再打开任务管理器 → 性能 → 磁盘，复制一个大文件，看读写速度的变化。

避坑

设备管理器里带黄色感叹号先看驱动，别急着重装系统；中断和 DMA 知道是干什么的就行，不用背细节。
