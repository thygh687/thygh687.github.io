模块一第 5 章：总线与输入输出

组成原理2026-11-24 · 模块一

CPU、内存、硬盘、显卡之间要传数据，走的都是总线。总线就是电脑里的路，路越宽、一次能运的东西越多。

三种总线

数据总线运数据，地址总线指明数据要去哪个地址，控制总线发命令（读还是写）。地址总线的宽度决定了 CPU 能管多大的内存：32 位地址最多管 4GB 内存，64 位地址就大得用不完了，这也是 32 位系统认不出 4GB 以上内存的原因。

输入输出设备

键盘、鼠标、显示器、网卡、硬盘都是输入输出设备。CPU 通过端口跟它们打交道：往端口写数据就是发命令，从端口读数据就是收结果。还有一种方式叫内存映射 I/O，就是把设备的端口当成内存地址来访问，写内存就等于在操作设备。

中断：有事再叫我

设备有事的时候会打断 CPU 一下：比如你敲了一个键，键盘就发个中断，CPU 停下手里的活，先处理这个按键，再回去继续。这比轮询好得多——轮询是 CPU 不停地问每个设备“有事吗”，大部分时间都在白问；中断是“有事设备自己会说”，CPU 可以安心干别的。

DMA：大块搬运不用 CPU 盯着

从硬盘读一个大文件，不用 CPU 一点一点盯着，DMA 控制器直接在内存和硬盘之间搬，搬完告诉 CPU 一声就行。省下来的 CPU 时间可以干别的。第 9 章会把中断和 DMA 展开细讲。

动手做

1. 右键“此电脑” → 管理 → 设备管理器，看一眼自己电脑的设备：处理器、磁盘驱动器、网络适配器都在。
2. 插拔一次 U 盘，看设备管理器里是不是多了一个设备又消失了。
3. 打开任务管理器 → 性能 → 磁盘，复制一个大文件，看读写速度的变化。

避坑

设备管理器里带黄色感叹号先看驱动，别急着重装系统；中断和 DMA 知道是干什么的就行，不用背细节；32 位和 64 位的区别先记住“内存寻址”这一条就够了。
