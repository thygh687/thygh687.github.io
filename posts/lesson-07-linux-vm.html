第 7 课：为什么学 Linux：先装个虚拟机

Linux2026-11-24 · 阶段二

第 6 课的三条命令是在 Windows 里跑的，从这一课起，战场换到 Linux。不是因为 Windows 不好，而是因为安全这行的大部分工具和大部分服务器，都生在 Linux 上。

为什么要学 Linux

三个理由，每一个都绕不开：

  • 工具生在 Linux 上。后面要用的安全工具——抓包、扫描、日志分析——绝大多数先有 Linux 版本，有些甚至只有 Linux 版本。不会 Linux，工具装不上、命令看不懂，路就断了。
  • 服务器大多是 Linux。网站、云服务、公司内网的服务器，绝大多数跑 Linux。你以后要保护的、要检查的、要排错的机器，十有八九是它。只会 Windows，等于只认识一半的战场。
  • Linux 把“规矩”摆在明面上。第 1 课说过，操作系统是大管家，定规矩。Windows 的规矩很多藏在图形界面后面，Linux 的规矩直接写在文件和权限里——谁能读、谁能写、谁能执行，一眼就能看到。学安全就是学规矩，所以 Linux 是最好的练功场。第 9 课就会从这里入手。

什么时候不用急着学 Linux？如果只是日常用电脑、修电脑，Windows 完全够用。Linux 不是“更高级的电脑”，它只是在安全这条路上绕不开的一站。目标要清楚：我们学 Linux，是为了用它的命令行和工具，不是为了换个系统过日子。

常见误区：以为学 Linux 就是背几百条命令。不是。命令是查得到的（第 8 课会讲 man 怎么查），真正要学的是 Linux 的思路——一切皆文件、权限分得清、出了问题先看日志。这三点想通了，命令自然越用越顺。

什么是虚拟机

虚拟机就是在 Windows 里面再装一台电脑。它是“假”的电脑，但用起来跟真的一样：有自己的系统、自己的文件、自己的网络。关键的好处只有一个：玩坏了删掉重来，主力系统一点事没有。

为什么不用“双系统”（真机上再装一个 Linux）？双系统是把 Linux 装进真实硬盘，分区一旦动错，Windows 也可能跟着遭殃；而且每换一次系统就要重启一次，练起来很别扭。虚拟机不用动硬盘、不用重启，关掉就是一个窗口，删掉就是一个文件。对初学者来说，这是唯一正确的起点。

虚拟机和真机有什么不一样？对学习来说，几乎没有：命令一样、文件一样、网络一样。差别只在两处：一是性能——虚拟机分到的资源有限，跑大程序会慢一点，但学命令完全感觉不到；二是硬件——虚拟机里的“网卡”“硬盘”都是模拟出来的，练命令够用，但想练真实硬件排错，还得回真机。记住这个边界，就不会在虚拟机里纠结“为什么网速没真机快”这种假问题。

配置：分多少才够

这台电脑内存 64GB，跑虚拟机很轻松。给虚拟机分 8GB 内存、4 核 CPU、50GB 硬盘（动态分配，用多少占多少），装个 Ubuntu 桌面版，够用了。

这几个数字不是随便定的：

  • 8GB 内存：Ubuntu 桌面版自己就要吃掉约 2GB，剩下的留给浏览器和工具。分 4GB 也能开机，但一开浏览器就卡，练着练着就烦了；分 16GB 是浪费——主力系统还要留足余量。
  • 4 核 CPU：编译、解压、跑扫描工具时，核数直接决定快慢。1 核能跑，但装系统都要等半天；4 核是个舒服的平衡点。
  • 50GB 硬盘，动态分配：“动态分配”的意思是先只占一点地方，用多少、长多少，上限 50GB。别选“固定大小”——它会立刻在真机上划走 50GB，删虚拟机之前都拿不回来。50GB 听着大，但装完系统、装几个工具、攒几个实验文件，很快就用掉一半，留少了以后还得扩，更麻烦。

装哪个 Linux？先装 Ubuntu 桌面版。理由很实际：教程最多、出了问题搜得到答案、图形界面能兜底——命令卡住了，还能点鼠标先把事办了。等命令行熟了，再去碰那些没有桌面的服务器版。现在选“最容易上手的”，不是偷懒，是把精力留给命令本身。

虚拟机的网络：先用默认的 NAT

新建虚拟机时，网络默认是 NAT 模式：虚拟机能通过真机上网，但外面的机器看不到虚拟机。这对学习正好——虚拟机能上网装软件、查资料，又不会把实验里的服务暴露出去。第 10 课会用 ip a 亲眼看到这张虚拟网卡，到时候再回头看这个选择就明白了。

另一个模式叫“桥接”，虚拟机就像直接插进了你家路由器，拿一个和真机平起平坐的地址。现阶段别用：它会把虚拟机暴露给整个局域网，实验里开错一个服务，家里别的设备都看得见。等你知道自己在干什么了，再换不迟。

老师经验：装好系统第一件事不是学命令，是先拍一个快照（Snapshot）。快照就是给虚拟机存个档：以后不管把系统折腾成什么样，一点“恢复快照”，立刻回到刚装好的干净状态。修电脑的经验也一样——动手之前先想好怎么回滚。没有回滚方案的实验，等于在真机上裸奔。还有一条：虚拟机里的实验，永远别拿到真机、真实网站上去试。课程里所有实验都只在虚拟机里做，这条红线从第一天就要立住。

避坑：一是装系统时如果提示“虚拟化未开启”，要去电脑的 BIOS/UEFI 里打开 VT-x/AMD-V——虚拟机跑不起来，十有八九是它没开；二是别在虚拟机里用 root 账号日常操作，权限越大、误操作代价越大，第 9 课会讲为什么平时要用普通用户加 sudo；三是快照别拍太多，拍多了占硬盘，关键节点（刚装好系统、装好一套工具）各拍一个就够了。

动手做

去官网下载 VirtualBox 和 Ubuntu 桌面版镜像，打开 VirtualBox，新建一台虚拟机：内存 8GB、CPU 4 核、硬盘 50GB 动态分配、网络保持默认 NAT，按向导装好系统，第一次开机进到桌面。装好就先别急着学命令，熟悉一下桌面环境，再拍第一个快照——名字就叫“刚装好”。然后打开终端（下一课要用），确认它能打开、能打字，就收工。

装好了，下一课就开始在终端里敲第一批命令。虚拟机和 Linux 的关系，模块二的操作系统入门还会从“大管家怎么管资源”的角度再讲一遍，到时候对照着看，理解会更深。

本课小结
  • 学 Linux 是因为工具和服务器大多在 Linux 上，而且它的规矩摆在明面上，最适合练安全。
  • 虚拟机是在 Windows 里再装一台电脑：玩坏了删掉重来，主力系统不受影响；初学者不要用双系统。
  • 配置：8GB 内存、4 核 CPU、50GB 动态分配硬盘，装 Ubuntu 桌面版；网络先用默认的 NAT。
  • 装好系统第一件事是拍快照——动手之前先想好怎么回滚。
  • 所有实验只在虚拟机里做，绝不在真机和真实网站上练手。
